# Fonts

Fonts the sample data builder uses to draw scanned check images. They are committed here so the images look the same on every machine and never depend on fonts installed with Windows.

| Font | Used for | License |
|---|---|---|
| Caveat | Handwriting | SIL Open Font License 1.1 ([Caveat-OFL.txt](Caveat-OFL.txt)) |
| Patrick Hand | Handwriting | SIL Open Font License 1.1 ([PatrickHand-OFL.txt](PatrickHand-OFL.txt)) |
| Kalam | Handwriting | SIL Open Font License 1.1 ([Kalam-OFL.txt](Kalam-OFL.txt)) |
| Homemade Apple | Signatures | Apache License 2.0 ([HomemadeApple-LICENSE.txt](HomemadeApple-LICENSE.txt)) |
| Mrs Saint Delafield | Signatures | SIL Open Font License 1.1 ([MrsSaintDelafield-OFL.txt](MrsSaintDelafield-OFL.txt)) |

All five come from the [google/fonts](https://github.com/google/fonts) repository. Printed text on checks uses Open Sans (Regular, Semibold, Bold), copied from the web fonts Rock ships in `RockWeb/Assets/Fonts/OpenSans` and licensed under the Apache License 2.0 ([OpenSans-LICENSE.txt](OpenSans-LICENSE.txt)).

When adding a font, add its license file next to it and a row to this table.
