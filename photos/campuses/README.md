The [manifest](manifest.json) maps every photo to the existing campus key and Guid in [configuration/campuses.json](../../configuration/campuses.json). It records native dimensions, generation prompts, source artwork, and review notes. PNG originals are unchanged image-generator outputs. JPEGs retain the full native size, use quality 90, and have metadata removed.

## Reusing the photos

Use the relevant campus image as an actual visual reference for future scenes at that location. Use [the approved logo](../references/church/branding/rock-solid-church-logo.png) whenever church branding is visible. Keep the venue types and each building's roofline, materials, and entry arrangement distinct. Goodyear sets up and tears down every Sunday, so it uses removable church branding at a fictional school, not permanent church signs on school walls. Scottsdale was an independent church before it merged with Rock Solid Church, so it keeps its older sanctuary, steeple, and stained glass.

These venue assignments define visual references. No real property, school, or address is depicted. Existing campus names, Guids, service times, and data about rooms are unchanged. The original twelve-view [church reference pack](../references/church/README.md) describes Phoenix, not all seven buildings.

The public site's campus cards and brand downloads use this set. These photos are not yet assigned to campus image fields by the Rock package builder or loader.
